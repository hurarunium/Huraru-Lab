## 概要

C#(.NET 10)で作ったオセロのAIを、WebAssemblyにしてブラウザで動かす実験。AIはデスクトップ版の `ConsoleOthello` とまったく同じコード(ビットボード・NegaScout・置換表・終盤の完全読み・約3,000万局面から学習したパターン評価)で、レベル1〜15を選んで対戦できる。

ふらるラボのほかの作品はビルドなしの素のHTML/JSだが、この作品だけは、C#をビルドした結果(`_framework/` の .NET の実行環境とAI)を含む。画面(`index.html`・`game.js`)と、AIを動かす `worker.js` は、素のJSのまま読める。

## 試したこと

- 盤面のルール(合法手・裏返し・パス・終局)はJSで持ち、AIの手だけを Web Worker の中の C# に聞く。`[JSExport]` で C# の関数をJSから呼ぶ(Blazorは使わない)
- AIは、最初に「ゲーム開始」を押したときに読み込む(約9MB)。一覧ページのプレビューでは、盤面の絵だけを表示して軽く保つ
- 評価ファイル(18MB + 7MB)は gzip で約7MBにして配り、ブラウザの `DecompressionStream` で戻してから C# に渡す
- 置換表は、デスクトップ版の約800万件(192MB)から約100万件(24MB)に減らした。スマホのメモリを考えて。レベル15の速さはほとんど変わらなかった

## 気づき

- 最初は .NET のインタプリタで動かしたが、終盤の完全読みがデスクトップ版の約14倍遅く、レベル10以上で1手が最大36秒かかった。AOT(先にWebAssemblyへ変換する)にすると、デスクトップ版とほぼ同じ速さになった(レベル15で1局の1手の最大が約4秒)
- ただし、片方が大差で勝っている終盤(残り20マス)で、1手に20秒以上かかる局面が見つかった。デスクトップ版でも同じだったので、AIの側で直した。同じ値の手がいくつも並び、「これより良くはならない」ことを手ごとに確かめるのに時間がかかっていた。完全読みに、確定石(もう裏返らない石)から値の上限を決めて打ち切る工夫を入れると、その局面は1.5秒になった。ブラウザ版でも、レベル15の1局で1手の最大は約4.8秒
- 同じ局面・同じ置換表の大きさなら、ブラウザ版とデスクトップ版は1手も違わない手を選ぶ。読んだ局面の数まで一致したので、同じ探索をしていると確かめられた
- `_framework` のように `_` で始まるフォルダは、GitHub Pages の Jekyll が公開しないため、サイトの直下に `.nojekyll` を置いた
